## Como navegar

A estrutura do projeto segue o modelo abaixo:

* `README.md`: apresenta o caso, o envelope, os integrantes e a navegação do grupo.
* `1-matriz/matriz.md`: contém a matriz de estilos arquiteturais e a análise dos estilos considerados e descartados.
* `2-arquitetura/`: reúne a proposta arquitetural, incluindo diagramas C4, restrições e decisões de arquitetura em ADRs.
* `3-spike/`: armazena estudos exploratórios, scripts, documentação e resultados do experimento.
* `4-leitura-cruzada/`: reúne as objeções e respostas recebidas durante a leitura cruzada.
* `5-final/CHANGELOG.md`: registra as mudanças realizadas após a leitura cruzada e a versão final do trabalho.

*OBS: README será atualizado conforme o projeto progredir.*
